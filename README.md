# Autobank-X 銀行作業模擬

以網頁模擬一間銀行分行每天的作業。畫面包含各樓層平面、大廳、叫號看板，以及員工與客戶的即時動態。純前端專案，不需要安裝或建置。

## 使用方式

- 直接用瀏覽器開啟 `index.html` 即可執行模擬。
- 也可以啟動本機伺服器，例如 `python3 -m http.server`，再開啟 `http://localhost:8000/`。
- `admin.html` 是後台設定頁面。設定會存在瀏覽器的 localStorage。模擬頁偵測到變更時會出現提示，可以選擇「套用並重置」或「僅套用營運參數」。
  - 建議用本機伺服器開啟。部分瀏覽器在 `file://` 下不會讓兩個頁面共用設定。

## 模擬規則（預設值，皆可於後台調整）

| 項目 | 說明 |
| --- | --- |
| 時間 | 24 小時制。模擬時間與真實時間 1:1（1 秒 = 1 秒），可切換 2×～600× 倍速，也可快轉 1 小時或直接跳到下一天 |
| 日期 | 從 Day 1（星期一）開始 |
| 平日（一～五） | 08:00 開門營業；15:30 停止取號、不接新客，員工開始盤點作業；17:00 下班 |
| 週六 | 08:00～12:30 營業；12:30～15:00 員工盤點作業 |
| 週日 | 休假日，只有 ATM 24 小時服務 |

## 樓層

- **1F 營業大廳**：入口門廳、保全崗、ATM 區、取號機、大堂經理服務台、等候區、櫃台 1～N、櫃檯作業區、主管座位、數位服務區、叫號看板
- **2F 理財／貸款**：理財諮詢桌、貸款服務桌、企業金融桌、2F 等候區、貴賓理財室
- **3F 後勤／行政**：經理室、會議室、後勤作業區（收件匣／待送件匣、法遵座位）、員工休息室、收發室、更衣室
- **B1 金庫／檔案**：金庫（現金箱保管）、保管箱室、檔案室、監控機房、物料室

## 員工每日作業

1. **到班**：提早到班，在 3F 更衣室換制服、打卡。
2. **晨會**：在 3F 會議室舉行，由分行經理主持。
3. **開金庫**：櫃檯主管與經理雙人控管開啟金庫，櫃員到 B1 領取現金箱。
4. **開門營業**：保全開啟大門。櫃員與專員開始叫號服務，大堂經理引導客戶。
   - 部分交易需要主管授權，主管會走到該櫃台覆核。
5. **輪流午休**：分批進行，確保櫃台不會同時全部關閉。
6. **送件流程**：
   1. 交易產生的文件放在櫃台待收。
   2. 收發員定時收件，交給後勤作業區審核建檔。
   3. 需要核章的文件由經理核章。
   4. 收發員依送件時間把文件送往總行，回程帶回總行來文，交經理核閱後歸檔。
7. **運鈔車**：依排定時間到店，保全戒護到 B1 金庫，由主管交接現金（運補或解繳）。
8. **停止取號**：保全拉下鐵門（僅出不進），已取號的客戶仍會服務完畢。
9. **盤點作業**：
   1. 櫃員清點現金、軋帳、列印日結報表。
   2. 若有帳差，由主管查核。
   3. 櫃員繳回現金箱。
   4. 主管與經理盤點並封存金庫，經理簽核營業日報。
   5. 後勤執行日終批次。
   6. 收發員送出日結傳票。
10. **下班**：作業未完成的員工會留下加班。保全等所有人離開後，做最終巡檢並設定保全系統。

## 客戶流程

1. 進門，視需要先詢問大堂經理。
2. 在取號機選擇業務並取號：

   | 代碼 | 業務 | 辦理窗口 |
   | --- | --- | --- |
   | A | 存款／提款 | 1F 櫃台 |
   | B | 匯款／轉帳 | 1F 櫃台 |
   | C | 開戶／綜合業務 | 1F 櫃台 |
   | F | 外幣兌換 | 1F 櫃台（外匯櫃台） |
   | G | 信用卡／數位服務 | 1F 數位服務區 |
   | H | 保管箱 | B1 保管箱室（在 1F 等候） |
   | D | 理財諮詢 | 2F 理財桌 |
   | E | 貸款申辦 | 2F 貸款桌 |
   | I | 企業金融 | 2F 企金桌 |
   | V | 貴賓理財 | 2F 貴賓理財室 |
3. 到 1F 或 2F 的等候區等候叫號，再到指定櫃台辦理，辦完離開。
4. 等候超過耐心時間的客戶會放棄離開。
5. ATM 客戶 24 小時都可能出現。

## 職位

分行經理、櫃檯主管、櫃員、大堂經理、數位服務專員、理財專員、放款專員、企金專員、貴賓理專、保管箱專員、後勤作業、法遵稽核（定時抽查櫃台、日終法遵檢核）、收發送件、保全、清潔，另有外部的運鈔人員。

## 排班、請假與代班

- **排班**：每位員工可設定上班日（星期一～六）。週六只營業半天，同職務兩人以上者隔週輪值。
- **請假**：後台可預排假單（特休、病假、事假、公假等，全天／上午／下午），另有每日隨機臨時病假。上午假中午才到班；下午假到中午會交接（櫃員先繳回現金箱）後離開。
- **代班**：有人全天請假時，依序安排：
  1. 週六輪休的同職務同事調班
  2. 跨職務同事代理（例如後勤代櫃員、資深櫃員代櫃檯主管、企金專員代經理），原職務至少保留足夠人手
  3. 鄰近分行派員支援
  4. 都找不到時，該窗口當日暫停服務
- **排班表分頁**：顯示本週每人每天的狀態（班、休、請假、代班、調班、支援）。點今天或之後的格子即可請假或取消；當天臨時請假的人會交接後離開，並由鄰近分行派員約一小時後到班。

## 人物與角色特色

- **員工**：各職務穿著不同制服（經理領帶、櫃員絲巾、大堂經理綬帶、保全警帽、收發員郵差包、清潔圍裙），每人有資歷（新進／一般／資深，影響服務與盤點速度）與個人特色。
- **客戶類型**：上班族、長者、學生、商家店主、帶小孩的家長、外籍人士、企業主。各自有不同的步行速度、耐心與業務偏好（例如外籍人士多辦匯款、商家店主多辦存提款、長者走得慢但比較有耐心）。
- 等候中的客戶頭上會顯示號碼牌，等太久會出現「…」或紅色「!」。

## 臨時事件與排除動作

營業時間內會隨機發生突發狀況，由對應職務的員工依序執行排除動作；必要時通報外部人員到場。

| 事件 | 影響 | 排除動作 |
| --- | --- | --- |
| ATM 故障 | 該台 ATM 停止服務 | 大堂經理檢查、張貼公告 → 通報廠商 → 工程師到場維修 |
| 叫號機當機 | 改人工發號，取號變慢 | 大堂經理重新開機 →（部分情況）資訊廠商遠端修復 → 測試取號 |
| 核心系統斷線 | 所有窗口暫停交易 | 廣播安撫 → 後勤通報資訊處 → 搶修 → 主管測試恢復 |
| 停電 | 照明變暗、窗口與 ATM 停擺 | 保全至 B1 機電室啟動發電機 → 安撫客戶 → 等待台電復電 → 檢查設備 |
| 客戶身體不適 | 客戶倒地等待救護 | 大堂經理關懷、通報 119 → 保全取 AED → 救護人員送醫 |
| 天花板漏水 | 地面積水 | 清潔放置警示牌、拖地 → 通報物業 → 水電師傅修繕 |
| 火警警報誤報 | 全樓層警示 | 保全查看受信總機 → 現場確認、廣播 → 復歸警報 |
| 疑似詐騙（阻詐） | 長者臨櫃大額提領 | 櫃員關懷提問 → 主管協助 → 通報 165 → 員警到場勸阻（統計保住金額） |
| 發現偽鈔 | 櫃台暫停 | 櫃員暫扣 → 主管鑑定 → 填寫偽鈔收繳單（送總行） |
| 客戶客訴 | 久候客戶到服務台抱怨 | 大堂經理致歉 → 主管出面說明 → 安排優先辦理 |

- 樓層圖上會標示事件位置，並顯示積水、ATM 故障、救護車／警車、停電與警報等效果。
- 「臨時事件」分頁顯示每件事件的排除進度與負責人，也可手動觸發演練。
- 後台可開關各事件、調整頻率。

## 2.5D 立體顯示

樓層預設以 2.5D 斜角立體方式顯示，可在樓層區右上角切換「2.5D 立體／2D 平面」。

- 牆面有高度，採剖面手法：後方外牆完整高度並有窗戶，前方與室內牆降低，避免遮住人物。
- 櫃台、桌椅、櫃子、ATM、取號機、電梯等都是立體物件；人物為站立造型，會面向或背對鏡頭，走路時有步伐。
- 物件依前後位置排序繪製：坐在櫃台後的櫃員只露出上半身，坐在椅子上的客戶會被椅背遮住。
- 運鈔車、救護車、警車停在門口；臨時事件會在地面顯示脈動圈與標示。
- 家具與牆面預先繪製成背景，每格只重畫人物與擋在人物前方的家具，四層樓同時顯示仍維持流暢。

## 畫面功能

- **叫號看板**：最新叫號、近期叫號、各業務等候人數。可開啟叫號音效與語音叫號。
- **樓層平面**：可看全部樓層或單一樓層。滑鼠移到人物上會顯示狀態；點擊人物或員工列表可以追蹤該員工。
- **其他面板**：今日作業時程軸、服務窗口狀態、今日統計、送件流程、員工動態、事件紀錄。
- **每日營運報表**：每天 24:00 結算，可匯出 CSV。

## 後台設定項目

- 銀行與分行名稱
- 模擬起始日與時間、預設速度、亂數種子
- 每週各日的營業時間：上班、停止取號、下班
- 員工作息：到班提前時間、晨會、午休時段
- 業務項目：代碼、名稱、樓層、平均服務時間、比例、文件產生與核章機率
- 員工名單：姓名、職務、服務項目與叫號優先順序
- 每小時來客數與 ATM 使用量、耐心時間
- 送件時間與往返時間、後勤審核時間
- 金庫現金、運鈔時間、櫃員領用現金、帳差機率
- 可匯出或匯入 JSON，也可恢復預設值
